ELECTRICAL RING SIGNALS — THE KEY EFFECT:
  Create 3 orbital rings around the globe at different angles:
  
  Ring 1: equatorial (flat, horizontal ellipse around middle)
  Ring 2: tilted 35 degrees (diagonal orbit)  
  Ring 3: tilted 70 degrees (near-vertical orbit)

  Each ring:
    - Draw as a thin ellipse stroke
    - Color: rgba(100, 200, 255, 0.15) base
    - Width: 1.5px

  On each ring, animate a glowing "signal pulse" — 
  a bright dot that travels along the ring path:
  
  Signal dot:
    - Small circle radius: 4px
    - Color: #00d4ff (electric cyan)
    - Glow effect using shadowBlur: 20, shadowColor: #00d4ff
    - Each ring's pulse travels at different speed:
        Ring 1: 0.008 rad/frame
        Ring 2: 0.006 rad/frame  
        Ring 3: 0.010 rad/frame

        Draw 8 smaller dots behind it, each decreasing in 
        opacity and size (opacity: 0.8 → 0.05, size: 3px → 0.5px)
        This creates the electrical signal streak effect

  Additionally, add random spark events every 2-3 seconds:
    - A bright flash appears at a random point on a ring
    - Expands outward as a circle (radius 0 → 30px, opacity 1 → 0)
    - Color: rgba(255, 220, 100, 0.8) — golden spark
    - Duration: 600ms, CSS animation via JS-added class
