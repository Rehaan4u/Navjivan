  - Quick Actions card

Add this CSS:

@keyframes floatIn {
  from {
    opacity: 0;
    transform: translateY(28px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.animate-float {
  animation: floatIn 0.6s cubic-bezier(0.16, 1, 0.3, 1) both;
}

Stagger each block using animation-delay:
  Welcome banner card    : animation-delay: 0.05s
  Company Preferences    : animation-delay: 0.15s
  Quick Actions card     : animation-delay: 0.25s
  Any additional blocks  : animation-delay: 0.35s, 0.45s etc.

Add class "animate-float" to every top-level card/section block.
JS approach (if class-based approach not clean):

  document.addEventListener('DOMContentLoaded', () => {
    const blocks = document.querySelectorAll(
      '.banner, .card, .panel, [class*="card"], [class*="block"]'
    );
    blocks.forEach((el, i) => {
      el.style.opacity = '0';
      el.style.transform = 'translateY(28px)';
      el.style.transition = `opacity 0.6s cubic-bezier(0.16,1,0.3,1) ${i * 0.1}s,
                             transform 0.6s cubic-bezier(0.16,1,0.3,1) ${i * 0.1}s`;
      requestAnimationFrame(() => {
        setTimeout(() => {
          el.style.opacity = '1';
          el.style.transform = 'translateY(0)';
        }, 50);
      });
    });
  });
