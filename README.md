What it does
Navjivan delivers daily AI-powered newsletters about cloud companies
(AWS, Google Cloud, Azure) to subscribers every morning at 9AM IST.
Users select companies → AI fetches and summarises news → Beautiful
HTML email delivered automatically every day.

------

🚀 Want the full AWS cloud-native version?

branch for the complete serverless AWS infrastructure.

-------

Running Locally
Prerequisites

Node.js 20+
PostgreSQL (or Neon account)
Google OAuth credentials
Groq API key

----------
Tech Stack

Backend: Node.js, TypeScript, Express.js
Frontend: React 18, Vite, Tailwind CSS
Database: PostgreSQL (Neon serverless)
Auth: Google OAuth 2.0
AI: Groq API (llama-3.3-70b)
Email: Nodemailer / AWS SES
